# The a11y lab's results

What the lab's runs of 4 Nov 2026 measured, as read on 11 Nov 2026:
`analysis/` covers the SE and 17e setups of the first runs (`report.txt`,
`summary.txt`, `order.txt`, `results.json`), and `analysis-17e-sdk26/` the
17e built with the iOS 26.5 SDK. `tools/` holds the scripts that read the
runs' artifacts; `pixels.py`, which `analyse.py` imports, didn't survive the
scratchpad. The screenshots and raw test logs were in the runs' GitHub
Actions artifacts and aren't kept here.

Ammy's CLAUDE.md, "VoiceOver reads "Now Playing" before the song again, since
build 164", has what the runs found and what shipped.
